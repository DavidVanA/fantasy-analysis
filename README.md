# Yahoo fantasy analysis

It has not yet been decided what type of analysis is going to be perfromed on the data. Really, I just want to be able to have a push notification that says that a certain player is the best option to pick up. That's about it.

Uses the Yahoo Fantasy API. Authentication can be done by adding an `env` file that contains:

```
YAHOO_FANTASY_APP_ID="..."
YAHOO_FANTASY_CLIENT_ID="..."
YAHOO_FANTASY_CLIENT_SECRET="..."
```
